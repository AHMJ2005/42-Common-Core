================================================================================
                       LIBFT MAKEFILE DETAILED EXPLANATION
================================================================================

1. VARIABLES DEFINITION
-----------------------

NAME        = libft.a
  - What it does: Sets a variable named NAME containing the final library name.
  - Purpose: Avoids hardcoding 'libft.a' across multiple rules. If the library
    name ever changes, you update only this single line.

CC          = cc
  - What it does: Defines the compiler executable to invoke.
  - Purpose: 'cc' is the standard system C compiler (resolves to clang or gcc).

CFLAGS      = -Wall -Wextra -Werror
  - What it does: Compiler flags passed to every compilation step:
      * -Wall   : Enables standard compiler warnings.
      * -Wextra : Enables additional stricter warnings.
      * -Werror : Treats all warnings as errors (mandatory 42 requirement).

AR          = ar rcs
  - What it does: Configures the archiver command to create static libraries (.a):
      * r : Insert/replace object files in the archive.
      * c : Create the library silently if it does not already exist.
      * s : Write an object-file index (symbol table) into the archive for fast
            linker lookups.

RM          = rm -f
  - What it does: Sets the file removal command.
  - Purpose: The -f (force) flag ensures 'rm' will never prompt for confirmation
    and will not throw an error if the target file does not exist.


2. SOURCE LISTS & STRING SUBSTITUTION
-------------------------------------

SRCS        = ft_isalpha.c \
              ft_isdigit.c \
              ...
  - What it does: Holds the list of mandatory source files (.c).
  - The '\' character: Line continuation marker; allows breaking long lists cleanly
    across multiple lines.

BONUS_SRCS  = ft_lstnew.c \
              ...
  - What it does: Holds all bonus linked-list source files (.c).

OBJS        = $(SRCS:.c=.o)
BONUS_OBJS  = $(BONUS_SRCS:.c=.o)
  - What it does: Suffix pattern substitution.
  - How it works: Replaces the '.c' extension of each file in $(SRCS) and
    $(BONUS_SRCS) with '.o' (e.g., ft_atoi.c becomes ft_atoi.o).


3. RULES & TARGETS
------------------

all: $(NAME)
  - What it does: The default rule triggered by running 'make'.
  - Dependency: Depends on $(NAME) (libft.a). Make checks if libft.a is built
    or out-of-date and runs its rule accordingly.

$(NAME): $(OBJS)
	$(AR) $(NAME) $(OBJS)
  - Target: $(NAME) (libft.a).
  - Dependency: $(OBJS) (all mandatory compiled object files).
  - Recipe: Uses 'ar rcs' to pack all mandatory .o files into the libft.a archive.

%.o: %.c libft.h
	$(CC) $(CFLAGS) -c $< -o $@
  - What it does: Pattern rule defining how to compile any .c file into its .o file.
  - Dependencies:
      * %.c     : The corresponding source file.
      * libft.h : Header dependency; re-compiles the .o if libft.h is modified.
  - Automatic Variables:
      * $< : Refers to the first dependency (the source file, e.g., ft_memset.c).
      * $@ : Refers to the target (the object file, e.g., ft_memset.o).
      * -c : Compiles to object code without invoking the linker.

bonus: $(OBJS) $(BONUS_OBJS)
	$(AR) $(NAME) $(OBJS) $(BONUS_OBJS)
  - What it does: Compiles and adds the bonus linked-list objects to libft.a.
  - Dependencies: Depends on both $(OBJS) and $(BONUS_OBJS).
  - Recipe: Packs all mandatory and bonus .o files into libft.a.

clean:
	$(RM) $(OBJS) $(BONUS_OBJS)
  - What it does: Deletes all compiled .o object files, preserving source code
    and libft.a.

fclean: clean
	$(RM) $(NAME)
  - What it does: Runs 'clean' first (deleting .o files), then deletes libft.a.

re: fclean all
  - What it does: Performs a complete rebuild from scratch by running 'fclean'
    followed by 'all'.


4. SPECIAL DIRECTIVES
---------------------

.PHONY: all bonus clean fclean re
  - What it does: Declares these target names as virtual (phony) targets rather
    than actual filenames on disk.
  - Why it is critical: If a physical file named 'clean' exists in your folder,
    running 'make clean' would otherwise report that 'clean is up to date' and do
    nothing. .PHONY forces Make to always execute the rule.
================================================================================
EOF
